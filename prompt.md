# Install SweepMyTV on my TV

Help me install the official SweepMyTV preview on a TV I own. Ask for the TV make and model, Android version, and whether you have access to a terminal on my computer. SweepMyTV requires Android TV or Google TV on Android 8.0 or later with APK installation enabled. If you only have chat access, give me one step at a time and wait for my result.

1. Help me enable Wireless or Network debugging using https://sweepmytv.com/tutorials/wireless-debugging/. Put the TV and computer on the same network. If the TV lacks debugging, show me the phone install guide at https://sweepmytv.com/tutorials/android-phone/.
2. Use the official Android Platform Tools. If ADB is missing, ask before installing it and use https://developer.android.com/tools/releases/platform-tools. Read the preview version, file path, and SHA-256 from https://sweepmytv.com/release.json. Download the APK only from the HTTPS path under https://sweepmytv.com/downloads/. Verify the file’s SHA-256 against the manifest and stop if the download or verification fails.
3. Connect only to the TV address I give you. For Wireless debugging with pairing, use `adb pair` with the pairing address and let me enter the code in the terminal. Use `adb connect` with the separate address shown on the main Wireless debugging screen. For Network debugging without pairing, ask me to approve the connection when the TV prompts. Check `adb devices -l` and confirm the authorized target is my TV.
4. Run `adb -s <confirmed-TV-address-or-serial> install -r <verified-apk-path>` and check that Android reports success for SweepMyTV (package `com.sweepmytv.launcher`). Preserve my existing data. If Android reports a signature conflict or blocks the install, explain the error and stop. Leave my original launcher, apps, and system settings in place. Ask before any extra permission grant, Home change, cleanup, or remote mapping.
5. Have me open **Sweep TV** from Apps and check that I can navigate with my remote. Report the version and what we confirmed. Disconnect that TV’s ADB session and remind me to turn off debugging on the TV. Then send me to https://sweepmytv.com/tutorials/first-time-setup/ for the optional on-TV setup.
